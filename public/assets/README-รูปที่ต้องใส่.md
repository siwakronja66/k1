## ✅ วิธีตรวจว่าใส่ถูก

เปิด browser แล้วไปที่:
- `http://localhost:8090/assets/20854.jpg` → ต้องเห็นรูป

> **หมายเหตุ**: ถ้ารูปยังไม่ขึ้น ให้กด Ctrl+Shift+R (hard refresh) ครั้งเดียว
